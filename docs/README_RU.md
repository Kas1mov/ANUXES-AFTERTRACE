# ANUXES AFTERTRACE

**Inspect. Compare. Understand.** — «Исследуй. Сравнивай. Понимай».

**Настроенная версия проекта:** 0.2.0
**Разработчик:** Kas1mov
**Издатель:** ANUXES DIVISION
**Платформа:** Windows 10/11, WPF, .NET 8

ANUXES AFTERTRACE — локальный помощник для анализа файлов. Он собирает сведения о файлах, вычисляет хеши и сохраняет снимки папок, чтобы в дальнейшем можно было исследовать изменения. Это **не антивирус**: программа не определяет окончательно, безопасен файл или вредоносен.

## Текущие возможности

### Анализ файлов

- Выбор файла через диалог или перетаскивание в окно приложения.
- Вычисление SHA-256 потоковым чтением.
- Определение поддерживаемых форматов по сигнатурам заголовка (включая PE, PDF, PNG, JPEG, GIF, ZIP, 7-Zip, RAR и ELF).
- Сравнение расширения с фактическим форматом там, где это поддерживается.
- Выявление исполняемых файлов с двойным расширением, маскирующим документ.
- Чтение доступной информации о встроенном сертификате. Это **не** проверка цепочки доверия сертификата.
- Отображение найденных признаков с пояснениями и экспорт результата в JSON.

### Snapshot Engine — M1

- Выбор папки или диска и создание снимка состояния на текущий момент.
- Для каждого доступного файла сохраняются относительный путь, размер, время последнего изменения, атрибуты и SHA-256.
- Снимки сохраняются в JSON в `%LOCALAPPDATA%\ANUXES\AFTERTRACE\Snapshots`.
- В приложении отображается локальная история снимков; сохранённый снимок можно загрузить обратно.
- Во время сканирования показываются прогресс, количество обработанных файлов, общий объём и количество пропусков. Сканирование можно отменить.
- Символические ссылки и junction-папки пропускаются, а не обходятся.
- Недоступные файлы и файлы, изменившиеся во время вычисления хеша, записываются как проблемы снимка, а не считаются успешно обработанными.

Снимок — это инвентаризация, а не резервная копия: исходные файлы не копируются. AFTERTRACE только читает их — не запускает, не изменяет, не перемещает, не удаляет и не помещает в карантин.

### Change Detection, AUTO CHECK и отчёты — M2–M4

- Сравнение двух снимков по относительному пути и SHA-256.
- Классификация `ADDED`, `MODIFIED`, `DELETED`, `MOVED` и `RENAMED`. Если одновременно изменились папка и имя, показывается `MOVED`.
- Дубликаты одинакового хеша сопоставляются один раз в стабильном порядке относительных путей; неоднозначность сохраняется в отчёте.
- Снимки с проблемами отмечаются как неполные; удаление подавляется для путей, недоступных во время нового сканирования.
- `AUTO CHECK` ищет последний снимок именно для выбранного `RootPath`; первый запуск создаёт базовый снимок, последующие сохраняют новый снимок и отчёт сравнения.
- В интерфейсе есть прогресс, обработанные и пропущенные файлы, отмена, история снимков и проверок, фильтры изменений, счётчики и подробности выбранной записи.
- Отчёты хранятся отдельно в `%LOCALAPPDATA%\\ANUXES\\AFTERTRACE\\Reports`; выбранный отчёт можно экспортировать в JSON.

## Ограничения

- Предупреждение не доказывает наличие вредоносного ПО. Файл без подписи, неизвестного формата или с несовпадающим расширением может быть легитимным.
- Отсутствие предупреждений не означает, что файл безопасен.
- В приложении нет базы сигнатур вредоносного ПО, облачной проверки репутации, поведенческой песочницы или защиты в реальном времени.
- Проверка сертификата сообщает только о возможности прочитать сведения о нём. Она не подтверждает личность издателя и доверие к подписи.
- Символические ссылки и junction-папки пропускаются. Если файл меняется во время вычисления хеша, он отмечается как проблема и не включается в снимок как стабильная запись.

## Сборка проекта

Требования:

- Windows 10 или Windows 11
- .NET 8 SDK

Файл проекта находится в корне репозитория. Из этой папки выполни в PowerShell:

```powershell
dotnet restore .\ANUXES-AFTERTRACE.sln
dotnet build .\ANUXES-AFTERTRACE.sln -c Release
dotnet run --project .\Aftertrace.App.csproj
```

Для публикации автономной сборки Windows x64 запусти `build-release.bat`.
