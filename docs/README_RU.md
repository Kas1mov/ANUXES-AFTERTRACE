## Обзор

**ANUXES AFTERTRACE** — настольное приложение для Windows, предназначенное для статического анализа файлов. Оно позволяет изучать свойства файлов, вычислять хеш-суммы, определять поддерживаемые форматы по сигнатурам заголовков, просматривать информацию о встроенных сертификатах цифровой подписи и выявлять потенциально подозрительные признаки с помощью эвристического анализа.

Приложение разработано с использованием **C#**, **WPF** и **.NET 8**.

## Основные возможности (v0.1.1)

| Возможность | Описание |
|---|---|
| Выбор файла | Выбор файла через диалоговое окно или перетаскивание непосредственно в область сканирования. |
| SHA-256 | Вычисление хеш-суммы SHA-256 с использованием потокового чтения файлов. |
| Определение формата | Определение поддерживаемых форматов по сигнатурам заголовков файлов. |
| Проверка расширения | Сравнение расширения файла с определённым форматом, если он поддерживается. |
| Информация о подписи | Проверка возможности чтения информации о встроенном сертификате цифровой подписи. В этой версии не выполняется проверка цепочки доверия сертификата. |
| Результаты анализа | Отображение обнаруженных эвристических признаков с пояснениями. |
| Экспорт JSON | Экспорт результатов анализа в формате JSON. |

## Планы развития

Следующая цель разработки — **Snapshot System / Change Tracking** (система снимков и отслеживание изменений):

- Сохранение снимков выбранной пользователем папки или диска.
- Сравнение последующего сканирования с ранее сохранённым снимком.
- Обнаружение добавленных, изменённых, перемещённых, переименованных и удалённых файлов.
- Ведение истории снимков и экспорт отчётов о найденных изменениях.

**Функция Change Tracking находится в планах разработки и пока недоступна в версии 0.1.1.**

## Сборка и запуск

Клонируйте репозиторий:

```powershell
git clone https://github.com/Kas1mov/ANUXES-AFTERTRACE.git
cd ANUXES-AFTERTRACE
```

Восстановите зависимости и соберите проект:

```powershell
dotnet restore .\ANUXES-AFTERTRACE.sln
dotnet build .\ANUXES-AFTERTRACE.sln -c Debug
```

Запустите приложение:

```powershell
dotnet run --project .\Aftertrace.App.csproj
```

Для создания автономной сборки под Windows x64 выполните:

```powershell
.\build-release.bat
```

Готовая сборка будет сохранена в каталоге `publish\win-x64\`.

## Примечания и ограничения

- AFTERTRACE — это **помощник для анализа файлов, а не полноценный антивирус**.
- Предупреждение не является доказательством наличия вредоносного ПО. Файлы без цифровой подписи и неизвестные форматы могут быть совершенно легитимными.
- Отсутствие предупреждений не гарантирует безопасность файла.
- Проверка встроенного сертификата отображает доступную информацию о нём, но в текущей версии не устанавливает доверие к цепочке сертификатов.
- Файлы исследуются исключительно как данные. AFTERTRACE не запускает, не удаляет и не помещает проверяемые файлы в карантин.
- Отслеживание изменений на основе снимков (Snapshot-based Change Tracking) запланировано для будущих версий.
