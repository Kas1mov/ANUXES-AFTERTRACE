# ANUXES AFTERTRACE

**Inspect. Compare. Understand.** — «Исследуй. Сравнивай. Понимай».

ANUXES AFTERTRACE — Windows-приложение для локального статического анализа файлов. Оно помогает изучать свойства файлов, вычислять SHA-256, определять поддерживаемые форматы по сигнатурам и просматривать найденные эвристические признаки.

> **Текущая версия:** 0.1.1. Это помощник по анализу файлов, а не полноценный антивирус.

## Возможности текущей версии

- Выбор файла через диалог или перетаскивание.
- Вычисление SHA-256.
- Определение поддерживаемых форматов по заголовкам файлов.
- Сравнение расширения с определённым форматом там, где это поддерживается.
- Просмотр доступной информации о встроенном сертификате подписи. Проверка цепочки доверия сертификата в этой версии не выполняется.
- Просмотр эвристических находок с пояснениями.
- Экспорт результата анализа в JSON.

## План: Snapshot System / Change Tracking

В следующем этапе AFTERTRACE получит систему снимков выбранной папки или диска. Предполагаемый формат первого варианта — JSON-снимки с метаданными файлов и SHA-256.

Планируемые статусы сравнения:

- `ADDED` — новый файл.
- `MODIFIED` — изменилось содержимое файла.
- `DELETED` — файл отсутствует в новом снимке. Такой вывод допустим только если соответствующая область была успешно проверена.
- `MOVED` — файл найден по другому пути с тем же содержимым.
- `RENAMED` — файл переименован; определение будет опираться на сравнение снимков.
- `UNCHANGED` — проверенные данные совпадают.
- `NOT CHECKED` — файл или каталог не удалось надёжно проверить.

**Важно:** Change Tracking пока находится в плане разработки и не доступен в версии 0.1.1. Автоматическое расписание и постоянное наблюдение за папками также не реализованы.

## Сборка

Из корневой папки репозитория выполни:

```powershell
dotnet restore .\ANUXES-AFTERTRACE.sln
dotnet build .\ANUXES-AFTERTRACE.sln -c Debug
dotnet build .\ANUXES-AFTERTRACE.sln -c Release
```

Для публикации самостоятельной сборки Windows x64 запусти `build-release.bat`.

## Безопасность и ограничения

- AFTERTRACE анализирует файлы как данные и не запускает их.
- Предупреждение не доказывает наличие вредоносного кода.
- Отсутствие предупреждений не доказывает безопасность файла.
- Хеш SHA-256 помогает сравнивать содержимое, но сам по себе не устанавливает надёжность файла.
- Приложение не заменяет защитное ПО.
