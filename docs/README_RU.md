# ANUXES AFTERTRACE

**Inspect. Compare. Understand.** — «Исследуй. Сравнивай. Понимай».

ANUXES AFTERTRACE — Windows-приложение в разработке для локального анализа файлов и отслеживания изменений в папках. Его задача — помогать понимать свойства файлов и видеть, что изменилось между двумя моментами времени.

> **Статус проекта:** ранняя разработка / прототип. Возможности и интерфейсы могут меняться. Это ещё не готовая релизная сборка.

## Цели проекта

- Анализировать файлы локально, не запуская их.
- Вычислять SHA-256 и показывать метаданные.
- Изучать файловые сигнатуры и заголовки там, где это поддерживается.
- Создавать снимки папок и сравнивать их позднее.
- Объяснять найденные признаки, а не выдавать необоснованный вердикт «безопасно / опасно».
- По умолчанию хранить данные пользователя локально.

## Change Tracking

Первый вариант Change Tracking строится вокруг JSON-снимков. Снимок хранит сведения о файлах (относительный путь, размер, время последнего изменения и SHA-256). Исходные файлы не копируются, не перемещаются и не запускаются.

Планируемые статусы сравнения:

- `ADDED` — файл найден только в новом снимке.
- `REMOVED` — файл был в старом снимке, но отсутствует в новом; такой вывод допустим только при успешном обходе соответствующей папки.
- `MODIFIED` — изменился хеш содержимого.
- `METADATA CHANGED` — выбранные метаданные изменились, а хеш остался прежним.
- `UNCHANGED` — сравниваемые значения совпадают.
- `NOT CHECKED` — файл или папку не удалось надёжно проверить.

Автоматическое расписание и постоянное наблюдение за папками запланированы, но не должны считаться доступными, пока не будут реализованы и проверены в составе приложения.

## Безопасность и ограничения

ANUXES AFTERTRACE — **помощник по анализу файлов, а не антивирус**. Метаданные, хеши, подписи и эвристические признаки не могут сами по себе доказать, что файл безопасен или вредоносен. Отсутствие цифровой подписи не означает автоматически, что файл опасен. Не используй приложение вместо надёжного защитного ПО.
